# nyaware cs2 

external cheat for Counter-Strike 2 with a lot of functions pasted by impulse

## note
this cheat uses visible check by parsing map vertices from local .opt file.
if you want to play with, download maps_cache.zip and unpack all .opt files in: "C:\nyaware\maps_cache" folder so that cheat finds these files and can use them.
if you won't install - visible check will not work
